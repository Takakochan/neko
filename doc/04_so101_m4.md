# SO-101 を M4 Mac（Apple Silicon）で動かす手順

M1〜M4 の Apple Silicon の Mac では LeRobot が使えるので、アームの準備（ポート探し・キャリブレーション）を LeRobot の公式コマンドで行い、`arm_api` も LeRobot 経由で動かす。

> Intel Mac では LeRobot が入らない（PyTorch が古いため）。Intel Mac では LeRobot なしの `so101` バックエンドを使う（このページの最後を参照）。
> なお `so101` バックエンドは M4 Mac でも動くので、LeRobot で困ったときの代わりにもなる。

所要時間の目安：初回 30〜45 分（インストールが大半）

---

## 1. 準備（初回だけ）

### uv を入れる（入っていなければ）

```bash
curl -LsSf https://astral.sh/uv/install.sh | sh
```

ターミナルを開き直してから `uv --version` で確認する。

### リポジトリを取ってくる

```bash
git clone git@github.com:Takakochan/neko.git
cd neko
```

すでにある場合は `cd neko && git pull`。

### venv を作ってパッケージを入れる

```bash
uv venv --python 3.12
source .venv/bin/activate
uv pip install -r requirements/lerobot.txt
uv pip install --reinstall opencv-python==5.0.0.93
```

- 3 行目は `requirements.txt`（ビジョン・アーム共通）と LeRobot をまとめて入れる。PyTorch もここで入るので数分かかる
- **4 行目は省略しない。** LeRobot が画面表示のない OpenCV（`opencv-python-headless`）を入れて `cv2` を上書きするので、そのままだと `record_grid.py` のカメラ画面が出ない
- 新しいターミナルを開いたら、毎回 `source .venv/bin/activate` してから作業する（プロンプトの先頭に `(.venv)` が出ていれば OK）

確認：

```bash
python --version                                                 # Python 3.12.x
python -c "import lerobot, cv2; print(lerobot.__version__, cv2.__version__)"
```

---

## 2. アームをつなぐ

1. アームの電源アダプタをつなぐ（USB だけでは動かない）
2. USB を Mac につなぐ
3. ポートを調べる：

```bash
lerobot-find-port
```

表示に従って USB を抜き差しすると、`/dev/tty.usbmodemXXXX` のようなポート名が出る。以降の `<ポート>` はこれに置き換える。毎回打つのが面倒なら：

```bash
export ARM_PORT=/dev/tty.usbmodemXXXX
```

---

## 3. キャリブレーション（アームごとに一度だけ）

```bash
lerobot-calibrate --robot.type=so101_follower --robot.port=$ARM_PORT --robot.id=so101_follower
```

- 画面の指示に従う：腕を各関節の真ん中の姿勢にして Enter → 各関節を端から端まで動かして Enter
- 補正値はサーボ本体に書き込まれ、設定ファイルは `~/.cache/huggingface/lerobot/calibration/` に保存される
- `--robot.id` は `arm_api` の既定値（`so101_follower`）と同じにしておく。別の名前にした場合は、実行時に `ARM_ID=<名前>` を付ける

> Intel Mac の `python pc/so101_check.py calib` でキャリブレーションしたアームを使う場合も、M4 では一度 `lerobot-calibrate` をやり直す。サーボの補正値と LeRobot の設定ファイルが合わないと、LeRobot が接続時にやり直しを求めてくるため。

### 動作確認

角度が読めるか確かめる（アームは動かない）：

```bash
python -c "
from lerobot.robots.so_follower import SO101Follower, SO101FollowerConfig
r = SO101Follower(SO101FollowerConfig(port='$ARM_PORT', id='so101_follower'))
r.connect(); print(r.get_observation()); r.disconnect()"
```

腕を手で少し動かしてからもう一度実行し、数字が変わればつながっている。

---

## 4. grid.json を作る（カメラを固定したあと）

カメラの位置を決めてテープで印を付け、**以降は動かさない**。動かしたら作り直し。

```bash
python pc/record_grid.py --backend lerobot --port $ARM_PORT
```

1. アームが脱力するので、手で支えながら、じゃらしの先端を画面の目安の点（3×3）のあたりへ持っていく
2. `l` で今の姿勢のまま固定できる（もう一度 `l` で脱力）
3. 画面の中のじゃらしの先端をクリック → そのときの関節角度が記録される
4. 9 点記録したら、待機姿勢（猫に当たらない、たたんだ姿勢）にして `h`
5. `s` で `data/grid.json` に保存（前のファイルがあれば `grid.bak-日時.json` として残る）

キー：`u` 最後の点を取り消し / `q` 保存せずに終了

カメラの画面が出ないときは、システム設定 → プライバシーとセキュリティ → カメラ で、ターミナル（VS Code から実行するなら VS Code）を許可する。

---

## 5. 動かす

```bash
ARM_BACKEND=lerobot python pc/arm_api.py
```

待機姿勢に移動したあと、4 つの遊びモード（bird / mouse / peek / tease）を 3 秒ずつ動かす。統合ループから使うときも、`ARM_BACKEND=lerobot` を付けて起動すれば同じように `arm_api` が LeRobot 経由になる。

### 安全

- **非常停止はアームの電源を抜く。** `Ctrl+C` は PC 側を止めるだけ
- 大きな移動は 1 回あたり 15° ずつに分けて送るので、急には跳ねない
- LeRobot 版はプログラムが終わると自動で脱力する（`arm_api.py` も `record_grid.py` も）。腕が落ちるので、終わる前に手で支えるか、待機姿勢を台に乗る姿勢にしておく
- 最初は猫のいないところで、じゃらしを付けずに動かして確かめる

---

## うまくいかないとき

| 症状 | 原因と対処 |
|---|---|
| `cv2.imshow` でエラー / カメラの画面が出ない | OpenCV が headless 版になっている。`uv pip install --reinstall opencv-python==5.0.0.93` |
| `set ARM_PORT` と言われる | LeRobot 版はポートの指定が必須。`export ARM_PORT=...` か `--port` |
| 接続時にキャリブレーションを求められる | サーボの補正値と LeRobot の設定ファイルが合っていない。表示に従ってやり直すか、`lerobot-calibrate` を実行 |
| `grid.json was recorded with 'so101', not 'lerobot'` | grid.json を別のバックエンドで作った。関節角度の値の基準が違う（so101 は真ん中が 90°、lerobot は 0°）ので、`--backend lerobot` で作り直す |
| `needs a real data/grid.json` | grid.json がまだない。手順 4 で作る |
| ポートが開けない / busy | 他のプログラム（別のターミナルの Python など）がアームをつかんでいる。終了してから再実行 |
| `python` が 3.12 にならない | `source .venv/bin/activate` を忘れている |

## 参考：LeRobot を使わない方法（Intel Mac・M4 Mac どちらでも）

```bash
uv pip install -r requirements.txt
python pc/so101_check.py watch       # つながるか確認
python pc/so101_check.py calib       # キャリブレーション（補正値もサーボに書く）
python pc/record_grid.py             # grid.json（--backend so101 が既定）
ARM_BACKEND=so101 python pc/arm_api.py
```

ポートは自動で探す（複数あるときは `--port` / `ARM_PORT` で指定）。
